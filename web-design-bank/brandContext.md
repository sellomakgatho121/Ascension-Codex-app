## Visual Identity

### Logo Guidelines

#### Primary Logo
- **Symbol**: Sacred geometric pattern (Flower of Life inspired)
- **Typography**: Modern serif with ethereal qualities
- **Color**: Cosmic purple with golden accents
- **Usage**: Headers, splash screens, branding materials

#### Logo Variations
- **Full Logo**: Symbol + wordmark (primary use)
- **Icon Only**: Symbol alone (app icons, favicons)
- **Wordmark Only**: Text alone (minimal contexts)
- **Monochrome**: Single color versions for specific uses

#### Clear Space & Sizing
- Minimum clear space: 1x symbol height on all sides
- Minimum size: 32px height for digital, 0.5" for print
- Never stretch, distort, or rotate the logo
- Maintain aspect ratio at all times

### Color Usage Rules

#### Contrast Requirements
- **Text on Background**: Minimum 4.5:1 ratio (WCAG AA)
- **Large Text**: Minimum 3:1 ratio
- **Interactive Elements**: Minimum 3:1 ratio
- **Aim for WCAG AAA**: 7:1 ratio where possible

#### Color Combinations
✅ **Approved Combinations**
- Cosmic purple + Sacred gold (primary brand)
- Ethereal silver + Mystical violet (soft spiritual)
- Crystal clear + Cosmic purple (clean modern)
- Sacred gold + Deep purple background (premium)

❌ **Avoid Combinations**
- Red + green (accessibility issues)
- Low contrast combinations
- More than 3 primary colors in one view
- Overly saturated color combinations

## Typography

### Font Families

#### Primary Font: **Inter** (Sans-serif)
- **Usage**: Body text, UI elements, navigation
- **Weights**: 400 (Regular), 500 (Medium), 600 (Semibold), 700 (Bold)
- **Characteristics**: Clean, modern, highly readable
- **Fallback**: system-ui, -apple-system, sans-serif

#### Display Font: **Playfair Display** (Serif)
- **Usage**: Headings, spiritual quotes, emphasis
- **Weights**: 400 (Regular), 600 (Semibold), 700 (Bold)
- **Characteristics**: Elegant, spiritual, authoritative
- **Fallback**: Georgia, serif

#### Monospace Font: **JetBrains Mono**
- **Usage**: Code, technical content, data
- **Weights**: 400 (Regular), 500 (Medium)
- **Characteristics**: Clear, technical, readable
- **Fallback**: Courier New, monospace

### Typography Scale (Golden Ratio Based)

```
xs:   0.75rem  (12px)  - Captions, labels
sm:   0.875rem (14px)  - Small text, metadata
base: 1rem     (16px)  - Body text (default)
lg:   1.125rem (18px)  - Large body text
xl:   1.25rem  (20px)  - Small headings
2xl:  1.5rem   (24px)  - Subheadings
3xl:  1.875rem (30px)  - Section headings
4xl:  2.25rem  (36px)  - Page headings
5xl:  3rem     (48px)  - Hero headings
6xl:  3.75rem  (60px)  - Display headings
```

### Line Heights
- **Tight**: 1.25 (headings)
- **Normal**: 1.5 (body text)
- **Relaxed**: 1.75 (long-form content)
- **Loose**: 2 (spiritual quotes, emphasis)
