## Team Notes

### Design Decisions
- **Golden Ratio**: Using 1.618 ratio for typography and spacing for sacred proportions
- **Cosmic Purple**: Primary brand color chosen for spiritual consciousness association
- **Mobile-First**: All designs start with mobile, enhance for desktop
- **Accessibility**: WCAG AA minimum, AAA where feasible
- **Performance**: 60fps animations, <2s page load target

### Development Conventions
- **TypeScript**: Strict mode enabled, no `any` types
- **Components**: Functional components with hooks
- **Styling**: TailwindCSS utility-first approach
- **State**: React Query for server state, local state for UI
- **Testing**: Jest + React Testing Library (to be expanded)

### Content Guidelines
- **Authenticity**: All Energetic Synthesis content verified
- **Clarity**: Complex concepts explained progressively
- **Inclusivity**: Non-dogmatic, respectful language
- **Accuracy**: Sacred geometry mathematically correct
