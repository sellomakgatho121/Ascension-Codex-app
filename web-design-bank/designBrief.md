## Technical Stack

### Frontend
- **Framework**: React 18.3.1 with TypeScript 5.6.3
- **Routing**: Wouter 3.3.5
- **Styling**: TailwindCSS 3.4.17 with custom sacred design tokens
- **UI Components**: Radix UI primitives with shadcn/ui patterns
- **Animations**: Framer Motion 11.18.2
- **Icons**: Lucide React 0.453.0
- **State Management**: TanStack React Query 5.60.5
- **Forms**: React Hook Form 7.55.0 with Zod validation

### Backend
- **Runtime**: Node.js with Express 4.21.2
- **Database**: PostgreSQL with Drizzle ORM 0.39.1
- **AI Integration**: Anthropic SDK, Google Generative AI, OpenAI
- **Authentication**: Passport.js with session management

### Performance & Optimization
- **Build Tool**: Vite 5.4.14
- **Bundle Optimization**: Code splitting, lazy loading
- **Caching**: Service workers (planned)
- **CDN**: Netlify deployment
